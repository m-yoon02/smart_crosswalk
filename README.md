Smart cross walk system

interactive cross walk using button press and mobile application

User can use the android app to send signal to the cross walk;
1. whether they are on their way to the cross walk or at the cross walk.
2. tell the crosswalk system when they are planning on crossing.
3. according to the traffic condition(cars, or no cars) the application will tell the user to wait or cross.


Features
1. Used timer 1 (16bits)
2. Every tick the I2C will send a data to the phone and mini OLED, into the ring buffer.

IDE
1.MPLab IDE
2.UART and I2C
3.PIC24 with XC16 compiler , SNAP
